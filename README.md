# godot-lab1-forest

## Features
- Main scene: `Main.tscn`
- Two sprites: `player` (icon.svg) and `rock` (rock.png)
- Instanced scene: `tree.tscn` (added multiple times for a forest)

## What I Learned
- How to add and save 2D scenes and set textures
- How to instance one scene into another
- How to set a main startup scene
